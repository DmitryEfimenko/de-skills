# implement-spec-slice

Use this skill when you need to implement one safe, testable vertical slice from a larger approved specification.

## When to Use

- The specification is broad and needs incremental delivery.
- You need to reduce risk by constraining scope.
- You want explicit non-goals and validation evidence.

## What Good Looks Like

- A clearly bounded slice with no silent scope expansion.
- Tests or checks that prove acceptance criteria.
- A short list of next slices for follow-up work.
