# address-pr-comments

Use this skill when resolving review feedback on an active pull request.

## When to Use

- A PR has multiple unresolved comments.
- You need a structured triage and response workflow.
- You want to minimize regressions while applying feedback.

## What Good Looks Like

- Every comment has a decision and traceable action.
- Validation is rerun after change batches.
- Responses are concise and technically justified.
